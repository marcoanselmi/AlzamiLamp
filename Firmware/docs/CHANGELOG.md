# Changelog

All notable changes to the AlzamiLamp Firmware project will be documented in this file.

## [1.0.0] - 2026-05-21

### Added
- First release of the firmware.
- WS2812 LED strip control on GPIO 3.
- Tilt switch input on GPIO 1.
- WiFi AP/STA startup.
- HTTP server, with optional UDP and MQTT in STA mode.
